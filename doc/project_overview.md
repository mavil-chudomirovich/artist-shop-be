# Artist Shop & Commission Platform

## Project Overview

A single-artist anime merchandise shop and commission platform.

### Goal

Build a polished personal portfolio + e-commerce website where customers can:

* Buy physical merchandise
* Submit art commissions
* Track orders and commission progress
* Communicate directly with the artist

### Technology

Frontend:

* Next.js
* TypeScript
* Tailwind CSS

Backend:

* Go
* REST API
* Modular Monolith

Infrastructure:

* PostgreSQL
* Cloudinary
* Docker
* VPS
* Vercel

---

→ DISCONTINUED

Request
